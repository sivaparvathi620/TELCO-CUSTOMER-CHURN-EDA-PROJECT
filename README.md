# 📊 Telco Customer Churn – Exploratory Data Analysis & Prediction

## 📌 Project Overview

Customer churn is a major challenge in the telecom industry. This project focuses on performing Exploratory Data Analysis (EDA) and building a machine learning model to understand customer behavior and predict whether a customer is likely to churn (leave the service).

The analysis helps identify key factors influencing churn, which can assist businesses in taking preventive actions to improve customer retention.

## 🎯 Problem Statement

To analyze telecom customer data and predict customer churn based on demographics, service usage, and billing information.

## 🛠️ Tools & Technologies

Programming Language: Python

Libraries: Pandas, NumPy, Matplotlib, Seaborn

Machine Learning: Scikit-learn

Environment: Jupyter Notebook

## 🔍 Project Workflow

Data loading and inspection

Data cleaning and preprocessing

Handling missing values

Exploratory Data Analysis (Univariate & Bivariate)

Feature encoding and scaling

Model building using Logistic Regression

Model evaluation and interpretation

## 🔑 Key Insights

Customers with month-to-month contracts have higher churn rates

Low tenure customers are more likely to churn

Customers with higher monthly charges show increased churn risk

## 🤖 Machine Learning Model

Model Used: Logistic Regression

Task: Binary Classification (Churn / No Churn)

Evaluation Metrics: Accuracy, Confusion Matrix, Classification Report

The model achieved good accuracy (~80%), making it suitable for churn prediction at an entry-level data science application.
